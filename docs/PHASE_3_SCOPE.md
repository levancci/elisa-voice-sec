# Phase 3 scope

Phase 3 benchmarks digit verification only. It does not train or fine-tune a
model. The current embedding default is the swappable ECAPA int8 registry
entry; final embedding selection remains deferred to CP6.

The current recordings already contain quiet/noisy connected four-digit
strings. Extra accented-English recordings are useful for the later evaluation
but are not required to begin this Phase 3 baseline. Please collect them with
the same protocol, adding an accent/device note to the manifest.
